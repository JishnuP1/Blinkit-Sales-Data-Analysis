# Blinkit-Sales-Data-Analysis
This project presents an exploratory and summary analysis of Blinkit's sales data using Microsoft Excel. It includes data cleaning, pivot-based KPI aggregation, and an interactive dashboard to help uncover business insights such as total sales, customer ratings, and product performance.
Objectives
Understand the performance of Blinkit’s sales.

Derive actionable KPIs such as:

Total Sales

Average Order Value

Number of Items Sold

Customer Ratings

Provide a dashboard to visualize and interact with key metrics.

Key Insights
From the analysis of Blinkit data:

Total Sales: ₹1,201,681.49

Average Order Value: ₹140.99

Total Items Sold: 8,523

Average Customer Rating: 3.97 / 5

Interpretation: Sales performance is steady with moderate customer satisfaction. There's potential for improving both revenue and ratings through targeted promotions or service enhancements.

Tools Used
Microsoft Excel (Pivot Tables, Charts, Dashboard)

Raw transactional and customer data

How to Use
Download or clone the repository.

Open BlinkIT Data Analsysis.xlsx in Microsoft Excel.

Navigate through:

Raw Data: For detailed transactions.

Pivot Table: For summary metrics.

Dashboard: For visualized insights.
